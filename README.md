# My Portfolio 🚀

A modern and responsive personal portfolio website designed to showcase my skills, projects, education, experience, and development journey.

## 📌 About the Project

This portfolio website serves as a personal digital profile where I showcase my technical skills, projects, learning journey, experience, and contact information.

The website is designed with a modern dark-themed interface and responsive layout to provide a clean and engaging experience across desktop, tablet, and mobile devices.

It includes dedicated sections for About Me, Resume, Portfolio, Blog, and Contact.

⚙️ Installation & Setup

No backend or database is required for this project.

1. Clone the Repository
git clone https://github.com/YOUR-USERNAME/my-portfolio.git
2. Open the Project
cd my-portfolio
3. Run the Website

You can simply open:

index.html

in your web browser.

Using VS Code Live Server

For the best development experience, open the project in VS Code and use the Live Server extension.

Right-click:

index.html

and select:

Open with Live Server

The website will open in your browser.
